# Sora 2.0 产品方案与用户体验规范

## 1. 产品定位与目标用户

**产品定位**：Sora 是一个面向**普通基金与股票投资者（日常交易者）**的智能投研平台，帮助用户发现产业和市场变化，用极简标签理解相关公司近期受到的影响，透视基金的真实底层配料，并持续跟踪和复盘自己的研究判断。

### 1.1 目标用户特征（普通投资者 vs 职业交易员）

- **不是机构量化或全职盯盘手**：不需要满屏 MACD / KDJ / 复杂 K 线图，也不需要拗口的卖方研报黑话。
- **核心诉求是“3 秒扫读、10 秒对比”**：
  1. **看股票**：“这只重仓股（如 `MU` 美光、`NVDA` 英伟达）最近受什么利好驱动？有什么逆风风险？下季度盯什么？”——用几个字的胶囊讲清楚。
  2. **看基金**：“这只基金（如 `SOXX`、`AIQ`、`2800.HK`）到底装了什么配料？含多少 AI 存储、多少算力芯片？和另一只基金比有什么区别？”
  3. **看自己的关注与持仓**：“我关注或持有的这几只基金，底层一共关联了哪些核心公司？最近整体受什么影响？我之前看好的研究逻辑还成立吗？”

### 1.2 功能边界与非目标

- **不以复杂 K 线、高频交易、自动喊单为核心**。
- **不将新闻堆砌或单纯的持仓罗列视为智能投研**，所有事件与持仓均服务于“产业变化 → 公司影响 → 基金暴露 → 验证跟踪”的闭环。
- **严格区分事实、研究推断与不确定性**，不承诺自动超额收益（Alpha）预测。

## 2. 面向普通投资者的五大 UX 设计准则

### 2.1 准则一：用「几字影响胶囊」替代长篇分析（Stock Impact Pills）

每家覆盖公司均提炼 3~5 个字数不超过 16 字的短标签（`impactTags`），通过色彩与语义前缀直接表达：

- **`🟢 顺风利好`（`positive`）**：基于最新财报已兑现的正面驱动（如 `HBM 产能已锁死`、`数据中心收入翻倍`）。
- **`🟠 逆风风险`（`headwind`）**：业务中存在的拖累或外部约束（如 `手机电脑复苏慢`、`受区域出口管制约束`）。
- **`🔍 跟踪观察`（`watch`）**：下季财报或行业验证的观察点（如 `盯下季毛利率斜率`、`盯下代 HBM 量产`）。
  同时附带 **`roleTag`（产业链角色，如 `AI 内存主力`）** 与 **`purityTag`（业务纯度，如 `纯存储大厂` / `CPU+GPU 混合`）**，防止用户把混合业务公司误认为 100% 纯概念股。

### 2.2 准则二：用「基金配料表」透视真实暴露（Fund Ingredient Bar）

将基金披露持仓转化为直观的分段配料条：

- 自动计算并可视化展示每只基金在 **`🟩 AI 存储链`**、**`🟦 AI 芯片与光刻`** 与 **`⬜ 其他已披露持仓`** 的真实权重。
- 在 `/funds` 顶部提供 **2~3 只基金并排 PK 对照台**，一键对比不同基金的**交易门槛（美股 USD / 港股 HKD）**、**主题配料占比**、**近期影响胶囊**与**同日持仓重叠率说明**。

### 2.3 准则三：用「正反方拔河卡」防盲目追高（Pros & Cons Tug-of-War）

在每条研究线索（`/research` 与 `/research/:id`）顶部设置并排的 **三秒看懂正反方拔河卡**：

- 左列展示 **`🟢 看多理由（已披露事实）`**（`prosTags`）；
- 右列展示 **`🟠 泼盆冷水（潜在风险与干扰）`**（`consTags`）；
  帮助投资者在看到产业利好时第一时间识别反方风险与不确定性。

### 2.4 准则四：用「组合影响体检卡」串联个人关注与持仓（Portfolio Impact Health Check）

在 `/watchlist`（我的关注）与 `/portfolio`（我的组合）顶部自动生成 **组合近期核心影响体检**：

- 自动穿透用户已关注或已持仓的基金，识别底层共同持有的核心公司及宽基特征；
- 汇总为 **`🟢 顺风利好驱动`**、**`🟠 逆风风险提醒`** 与 **`🔍 下一步盯防`** 三栏胶囊，让用户一眼看清“我手里的基金最近整体受什么牵动”。

### 2.5 准则五：用「三态轻复盘打卡」替代沉重笔记（3-State Verdict Check-in）

在研究详情与关注列表中提供一键式复盘打卡：

- **`👍 逻辑继续成立`**（顺风驱动仍在兑现）
- **`🤔 存疑观望`**（等待下季财报确认）
- **`🛑 逻辑失效`**（逆风兑现或前提改变）
  点击即存本地浏览器，无需打字写长篇笔记即可完成投研跟踪闭环。

## 3. 核心业务对象与领域模型

| 业务对象                             | 代码模型                            | 核心职责与字段约束                                                                                                                                                                                               |
| :----------------------------------- | :---------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **产业主题（Theme）**                | `Domain` (`ai-storage`, `ai-chips`) | 承载 3 秒一句话看懂（`tldr`）、产业链环节（`nodes`）、核心公司、财报事件与基金持仓快照。                                                                                                                         |
| **产业链环节（Node）**               | `Domain['nodes'][number]`           | 将主题拆分为上下游节点（如 AI 存储链拆分为：`HBM 与高速内存`、`企业级大容量存储`、`存储制造与封装设备`）。                                                                                                       |
| **核心公司（Company）**              | `DomainCompany`                     | 包含 `symbol`、`name`、`nodeId`、`roleTag`、`purityTag`、`impactTags` 及官方财报来源 `sourceId`。                                                                                                                |
| **变化信号（Event）**                | `Domain['events'][number]`          | 记录具体财报期（`period`）、发布日（`publishedAt`）、短标签（`tags`）、已确认事实（`fact`）、研究解读（`interpretation`）与后续观察（`watch`）。                                                                 |
| **研究假设（Research Signal）**      | `ResearchSignal`                    | 包含 `themeId`、正反方短标签（`prosTags` / `consTags`）、事实证据链（`facts`）、传导路径（`chain`）、待验证假设（`hypothesis`）、反方逻辑（`counterpoints`）、基金映射（`funds`）与后续检查点（`checkpoints`）。 |
| **基金持仓快照（Holding Snapshot）** | `HoldingSnapshot`                   | 记录基金代码、披露日期（`asOf`）、覆盖范围（`full-equity` 完整权益或 `top-ten` 前十节选）、降序持仓明细与发行商来源。                                                                                            |
| **跨市场准入档案（Access Profile）** | `FundAccessProfile`                 | 覆盖全部目录基金的交易市场/币种门槛（`accessTag`）、配料定位（`ingredientTag`）与近期核心驱动（`recentDrivers`）。                                                                                               |

| :----------------------------------------- | :-------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 首页（Home）**                        | `/`                                           | 免登录产品介绍、核心个股影响胶囊与基金配料预览、观察方向快速入口。                                                                                                                                                |
| **2. 产业发现（Discover）**                | `/discover`（及 `/domains`）                  | 默认进入产业价值链透视（支持切换 **AI 存储产业链** 与 **AI 芯片**）；按环节筛选股票近期影响卡，点击公司联动右侧基金直接持仓权重。支持 `/discover?view=markets` 浏览全球市场与宽基观察方向。                       |
| **3. 深度研究（Research）**                | `/research` & `/research/:id`                 | 研究线索总览（支持按主题筛选）与研究详情页；展示正反方拔河卡、财报原文证据、传导链条、基金映射与三态复盘打卡。                                                                                                    |
| **4. 基金透视（Funds）**                   | `/funds` & `/funds/:code`                     | 顶部提供 2~3 只基金并排 PK 对照台；下方为支持关键词与主题筛选的基金目录；详情页依次展示**基金配料表**、**重仓股近期影响**、**已核对持仓明细**、**关联研究线索**与**日线收盘价走势**。                             |
| **5. 关注与组合（Following & Portfolio）** | `/watchlist`（及 `/following`）、`/portfolio` | `/watchlist` 汇总已关注研究线索（含下次大考提醒与三态复盘打卡）及关注组合近期影响体检；`/portfolio` 提供持仓组合近期影响体检、分币种（`CNY` / `USD` / `HKD` / `KRW`）份额与成本记录，以及本地 JSON 导入导出备份。 |

## 5. 已核对主题与基金数据基线

### 5.1 AI 存储产业链（`ai-storage`）

- **产业链节点**：`HBM 与高速内存`（`hbm-memory`）、`企业级大容量存储`（`enterprise-ssd`）、`存储制造与封装设备`（`storage-equipment`）。
- **覆盖公司与原始披露**：
  - `MU`（Micron 美光）：FY2026 Q4 业绩公告（发布 `2026-09-25`），确认 HBM 与数据中心收入高增，消费电子复苏温和。
  - `SKHY`（SK Hynix 海力士）：2026 Q3 业绩公告（发布 `2026-10-24`），HBM3e 供货推动营业利润创新高。
  - `WDC`（Western Digital 西部数据）：FY2027 Q1 业绩公告（发布 `2026-10-24`），云端收入占比过半，同时含传统机械硬盘周期。
  - `LRCX`（Lam Research 泛林）：FY2027 Q1 业绩公告（发布 `2026-10-23`），受益于 3D NAND 堆叠与 HBM 先进封装刻蚀升级。
- **基金直接持仓映射**：
  - `SOXX`（`2026-10-27` 完整 30 项权益持仓）：直接持有 `MU`（`7.70%`）、`LRCX`（`3.17%`）、`SKHY`（`2.69%`），合计确认 **AI 存储链权重 `13.56%`**。
  - `AIQ`（`2026-10-28` 前十大持仓节选）：前十以云平台、软件及算力芯片为主，前十节选中未出现存储原厂（标记为“前十未列出”，不视作零持有）。

### 5.2 AI 芯片与设备（`ai-chips`）

- **产业链节点**：`AI 算力芯片`（`compute-chips`）、`核心制造设备`（`litho-equipment`）。
- **覆盖公司与原始披露**：`NVDA`（FY2027 Q2 公告）、`AMD`（2026 Q2 公告）、`ASML`（2026 Q3 公告）。
- **基金直接持仓映射**：
  - `SOXX`：直接持有 `AMD`（`9.46%`）、`NVDA`（`7.85%`）、`ASML`（`1.47%`），合计确认 **AI 芯片与光刻权重 `18.78%`**（叠加 AI 存储链 `13.56%`，两大硬科技主题合计占 `SOXX` 达 `32.34%`）。
  - `AIQ`：前十节选列出 `AMD`（`2.92%`）、`NVDA`（`2.81%`），合计确认 `5.73%`。

### 5.3 跨市场代表性基金目录（`catalog.json`）

覆盖 `SOXX`（iShares 半导体 ETF）、`AIQ`（Global X 人工智能与科技 ETF）、`QQQ`（Invesco 纳斯达克100 ETF）、`IVV`（iShares 标普500 ETF）、`2800.HK`（盈富基金 · 港元柜台）与 `IAU`（iShares 黄金信托）。

## 6. 响应式、无障碍与离线 PWA 体验标准

- **全视口响应式适配**：桌面端（`>900px`）采用多栏工作台与完整表格；平板端（`641–900px`）采用双列卡片；手机端（`≤640px`）采用单列卡片、折叠主导航与下拉选择器，320px～1440px 全宽度无横向溢出，核心交互控件触控高度 `≥44px`。
- **键盘与读屏无障碍**：原生 `<dialog>` 模态框焦点环路与 Escape 恢复、表单错误 `aria-invalid` 关联与自动聚焦、筛选计数 `aria-live="polite"` 播报，以及站内多级返回路径的焦点与滚动位置精确恢复。
- **可控 PWA 离线与升级**：支持应用清单与离线壳预缓存；新版本就绪时采用手动确认升级，绝不强行刷新打断用户正在编辑的表单，且升级过程完全保留本地 `localStorage` 中的关注、复盘与持仓记录。
