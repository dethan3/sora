# Sora V2 产品方案

## 产品目标

面向普通投资者，以清晰、低信息负担的方式理解基金、观察市场、回看组合。
优先 Desktop Web，完成主要信息架构后完善响应式，最后增加 PWA。
不使用买卖指令或自动交易作为 M0 的产品承诺。

## 五个入口

| 入口     | 路由         | M0 行为                            | 后续模块               |
| -------- | ------------ | ---------------------------------- | ---------------------- |
| Welcome  | `/`          | 产品介绍与发现入口                 | 引导与使用说明         |
| 发现     | `/discover`  | 地区内容卡片，读取 JSON            | 市场、主题、内容模块   |
| 基金     | `/funds`     | 示例基金目录与名称、代码、市场搜索 | 筛选、详情、历史趋势   |
| 关注     | `/watchlist` | 只读示例关注列表                   | 本地关注增删、导入导出 |
| 我的组合 | `/portfolio` | 虚构组合总市值、成本、收益及分布   | 本地持仓录入与复盘     |

## M0 边界与验收标准

- [x] pnpm Workspace，TypeScript strict，React、Vite、Tailwind、React Router。
- [x] 五个路由可直接进入、相互导航；未知路由有返回入口。
- [x] 共享页面标题、面板、操作链接、空状态、变化值和基金表格。
- [x] HTTP 读取静态 JSON，边界校验、加载状态、失败提示与重试。
- [x] 所有展示数据标记虚构示例，展示快照日期；不伪装为真实行情。
- [x] 基金搜索支持无结果状态；组合收益由示例持仓计算。
- [x] 桌面布局优先；窄屏提供基础可读降级，完整响应式验收留到 M2。
- [x] 语义化导航与表格、输入标签、焦点样式、跳到主内容链接。
- [x] 基础测试、类型检查、生产构建、CI 与 Cloudflare 静态预览配置。
- [x] Python 代码、配置及测试保留在原路径，不与前端运行耦合。
- [ ] 真实 Cloudflare 预览 URL 验收：需配置账号与凭据后执行，M0 提交只交付配置及本地验证。

M0 不实现行情采集、D1、账户、Agent、MCP、服务端 API、PWA、持仓写入或关注持久化。
界面中不放置无法执行的保存、登录或添加按钮。

## 视觉原则

第一轮设计调整：清晰、精确、有活力、容易接近。

- 顶部主导航提供发现、基金、关注、我的组合；Welcome 保留 `/`，由 Logo 返回。
- 白色与冷灰底色、深墨蓝文字，蓝紫色作为品牌与交互重点；涨跌色独立。
- 首页使用有方向的彩色背景和产品预览，表达产品价值；功能页使用简洁标题、表格和数据分布。
- 首页预览的金额与占比来自同一份静态 JSON；折线仅为界面示意，明确标记“非历史净值”，不参与收益计算。
- 发现页以地区模块为主体；组合页突出总市值及实际示例持仓分布。
- 保持颜色与正负数字双重表达，中文市场使用红涨绿跌；所有数据保留虚构示例说明。
- 维持 M0 只读范围，不引入账户、持久化或真实行情；暂缓 M1。
