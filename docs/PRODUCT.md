# Sora V2 产品方案

当前阶段：先完成市场观察组件，以隔离的 Mock 行情验收页面与流程。市场范围为美股、国际资产及港股；不扩展中国内地市场。M0～M3 保留为历史验收记录，当前行为见文末。
M0 清单保留为历史基线，当前行为见文末。

## 产品目标

面向普通投资者，以清晰、低信息负担的方式理解基金、观察市场、回看组合。
优先 Desktop Web，完成主要信息架构后完善响应式，最后增加 PWA。
不使用买卖指令或自动交易作为 M0 的产品承诺。

## 视觉原则

第一轮设计调整：清晰、精确、有活力、容易接近。

- 顶部主导航提供发现、基金、关注、我的组合；Welcome 保留 `/`，由 Logo 返回。
- 白色与冷灰底色、深墨蓝文字，蓝紫色作为品牌与交互重点；涨跌色独立。
- 首页使用有方向的彩色背景和产品预览，表达产品价值；功能页使用简洁标题、表格和数据分布。
- 首页预览的金额与占比来自同一份静态 JSON；折线仅为界面示意，明确标记“非历史净值”，不参与收益计算。
- 发现页以地区模块为主体；组合页突出总市值及实际示例持仓分布。
- 保持颜色与正负数字双重表达，中文市场使用红涨绿跌；所有数据保留虚构示例说明。
- 第一轮视觉评审保留 M0 范围；评审后用户已授权继续 M1 本地交互开发。

### 计算口径

- 数据全部为虚构样本，固定快照 `2026-10-19`，不采集真实行情。
- 份额最多 4 位小数，净值最多 6 位小数；成本以币种最小单位整数保存。
- 估值 = 份额 × 当前样本净值，按币种最小单位四舍五入；CNY / USD 保留两位，KRW 为整数。
- 收益 = 市值 − 成本；成本为零时收益率显示“—”。
- CNY / USD / KRW 分别汇总，无汇率换算、不跨币种相加。
- 净值、目录缺失或币种变化时为“待估值”；该币种总市值、收益和权重暂停计算，单独展示已知市值。
- 曲线使用 JSON 样本日期和净值，时间轴按日期间隔排列，纵轴按样本范围缩放。
- 区间变化只比较所选样本首末净值，不含分红、费用或汇率，不形成买卖建议。

### 本地保存

数据保存在当前浏览器与站点地址内，换浏览器、端口或设备不会自动同步。
备份含 schemaVersion、关注代码和持仓；导入上限 1 MB，关注和持仓各最多 200 条。
导入校验后展示替换数量，经确认才写入；格式错误或保存失败不更改现有数据。
损坏或未来版本保留原文，允许下载后恢复，不自动覆盖为默认示例。
保存成功后才更新界面；其他页面通过 storage 事件同步，检测到冲突时提示刷新。

## M2 响应式与操作体验

- 768px 及以上直接显示导航入口；手机端为 68px 单行顶栏，导航链接默认折叠。最新入口布局见文末 Landing Page 导航约定。
- 手机菜单展开后纵向显示入口和当前页面状态；选择入口、点击外部或焦点离开导航后收起，Escape 关闭并恢复菜单按钮焦点。切换回桌面时清除展开状态。
- 大于 900px 保留基金、持仓表格；641–900px 为双列卡片，640px 及以下为单列卡片。
- 卡片包含市场、类型、币种、涨跌、估值与操作标签；关注、编辑和删除无需横向滚动寻找。
- 小屏表单使用单列和 16px 输入文字；主要按钮与控件至少 44px 高，适配安全区。
- 表单错误标记具体字段并聚焦；打开录入页时字段滚入可视区域，保存后返回录入按钮。
- 图表保持可读高度，日期和单位使用独立文字；历史明细可展开，通过表格读取数据。
- 确认弹窗聚焦“取消”，Tab / Shift+Tab 在操作按钮间循环，Escape 关闭并恢复焦点；背景禁止滚动。
- 列表使用同一份 DOM 和表格语义，避免桌面 / 手机各渲染一套可操作内容；筛选数量可被辅助技术感知。
- 支持减少动画偏好，不加入 PWA 或新的账户、行情与后端依赖。

M2 已完成 1440、1024、768、390px 浏览器尺寸检查和键盘 / 无障碍结构检查。
尺寸模拟不能代替真实 iOS / Android 键盘或 NVDA / VoiceOver 的人工体验，后续仍建议实机抽查。

## M3 安装、离线与更新

- 提供应用清单、192 / 512px 图标、独立 maskable 声明和 Apple 主屏幕图标；安装后以独立窗口打开。
- 浏览器提供原生安装机会时，页脚显示“安装 Sora”；其他情况下提供安装说明。安装相关入口保留在页脚。
- 首次成功联网准备内容后显示“可离线使用”。缓存包含完整页面、样式、图标和虚构示例 JSON；基金详情等深层路径也可离线刷新。
- 示例 JSON 与应用版本一起发布和缓存，不承诺联网时自动更新行情。页面始终显示虚构来源和快照日期；浏览器报告离线时增加缓存提示，尚未准备好时明确告知。
- 新版本准备好后显示更新入口；确认前提醒保存输入。取消不会修改输入，只有确认的页面主动刷新，其他打开的页面保留编辑状态并提示更新。
- 更新只处理应用资源缓存，继续读取原有 `sora.personal.v1`，不清空或迁移个人关注与持仓。个人备份方式保持不变。
- 注册或更新检查失败可重试，离线时不请求更新；不支持 PWA 的浏览器仍可使用普通网页。
- 内容缓存和个人数据均受浏览器存储策略影响；离线访问须先成功联网准备，不能保证从未访问过的设备首次离线可用。

## Landing Page 内容展开

Hero 与顶栏沿用已确认的设计。下方按首次访客的理解顺序展开：

1. 产品定位：Sora 连接地区、主题、基金和个人关注，为市场观察提供清晰路径。
2. 使用方式：从方向探索、基金研究到持续关注，搭配可切换地区 / 主题的产品示例。示例读取同一份 JSON，入口将所选方向带到基金目录。
3. 持续使用价值：集中关注、查看历史上下文，以及按需连接个人组合。关注预览明确为示意，不读取或改写用户的个人记录。
4. 选择理由：数据日期与币种明确、记录可导出备份、无需账户即可开始体验。
5. 常见问题：明确当前为虚构行情，账户尚未开放、存储限于当前浏览器与站点地址、不提供交易功能。
6. 开始体验：进入发现或基金目录，延续介绍页的探索路径。

页面使用叙事分栏、交互产品预览、深色价值区与可展开问答；窄屏按阅读顺序排列。营销内容不加入虚构客户、使用人数、收益保证或尚未实现的实时能力。核心入口须可用，JSON 读取失败时介绍与开始入口仍可访问。

本轮验收：79 项测试、格式、类型检查、生产构建及 PWA 产物检查通过；生产预览覆盖 320、390、768、1024、1440px 与四个观察方向的 20 种组合，均无横向溢出。切换方向进入筛选目录、页尾进入发现页、问答键盘展开和关闭均已检查。

## 市场组件与 Mock 体验 · 2026-10-26

本节覆盖上一节的空行情行为，仅在开发或明确选择的 Mock 预览中生效。正式构建继续提供资料目录和空行情。

- `MarketQuote` 在完整方向卡、个人观察卡和详情复用，显示参考指标值、单位、相对前一交易日的变化、交易状态及带时区的报价时间。上涨为绿、下跌为红、持平及缺失为中性，符合当前国际市场范围。
- `MarketHistory` 提供 1 周 / 1 月 / 3 月 / 1 年日线。区间基于最后一条观察记录的日期计算，月末截断到有效日期；区间变化和日变化分别标识。纵轴按区间缩放，日期滑块支持键盘和触摸，明细可展开。
- 数据状态覆盖载入中、失败重试、无报价、历史不足、延迟、休市和更新滞后。更新失败后如仍有有效记录，保留原值及原时间，不冒充最新数据。
- Mock 为确定性的人工数列，并非任何供应商的价格；页面显示“演示行情”。不生成新闻、涨跌原因、热度、排名或交易建议。
- 港股入口为香港市场 / 恒生指数，关联盈富基金（2800.HK）。原沪深300与 510300 不再进入公开目录；已有个人存储保留，未知方向和产品走原有不可用提示，不暗中删除或迁移。
- HKD 支持成本输入、保存、独立汇总和原有备份格式。指数 Mock 不写入基金净值或持仓估值，相关基金仍可录入成本并显示待估值。
- `pnpm dev` 默认启用 Mock；`pnpm --filter @sora/web build:mock` 与 `preview:mock` 提供独立生产预览。`pnpm build` 的 dist 不含 Mock 数据模块，Cloudflare 配置仍只指向正式 dist。
