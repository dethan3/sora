# Sora 2.0 模块化演进路线与阶段验收记录

## 0. 当前产品主线（2026-11-05）

用户明确 Sora 的初心为：**根据用户自定义的关注领域，寻找相关基金及可参与路径，像北极星一样提供方向。** 当前优先补齐这条用户体验；Phase 5.1～5.5 的本地基础继续保留，5.6 暂不推进。

**UI 决策更新（2026-11-05）**：用户已明确否决本轮浅色深青视觉原型，要求恢复原来的 UI。继续沿用现有应用的视觉和布局，不实施该重设计方案。原型未替换正式应用 UI 源码，既有 Phase 5 功能继续保留；领域寻找基金的产品目标不变。

被否决的独立原型已撤回，不作为实施依据。继续使用原项目 UI；真实领域检索和产品关系尚未接入，后续功能按以下顺序安排：

1. 首页与领域研究页围绕“关注什么领域 → 相关基金 → 参与路径”组织，支持自定义范围和用户可用市场 / 渠道条件。
2. 补齐领域、指数 / 资产 / 公司、基金、ETF 与联接的关系和证据；将主题相关性、覆盖程度与可达性分别表达。
3. 用指数方向、黄金、韩国半导体三个用户示例核对具体产品资料，验证直接与间接覆盖、渠道受限和暂无结果。
4. 将发现的方向及结果接到关注与账号保存，再评估正式部署。现有固定主题、公共目录搜索和基金关注不等于领域发现链路已经完成。

定位、交互和结果要求以 [产品方案第一节](./PRODUCT.md) 为准；下文保留既有工程阶段与历史验收记录。

## 2. Sora 2.0 产品级重构验收记录（2026-11-02 ～ 2026-11-03）

围绕“面向日常交易的普通投资者，用几个字的短标签讲清股票近期影响与基金真实配料”的核心方向，按四个递进阶段完成落地：

### 2.1 第一步 & 第二步：微卡片规范、AI 存储产业链与五大模块升级

- [x] **AI 存储产业链（`ai-storage.json`）落地**：覆盖 `HBM 与高速内存`、`企业级大容量存储`、`存储制造与封装设备` 三个产业链环节，收录 `MU`（美光）、`SKHY`（SK 海力士）、`WDC`（西部数据）、`LRCX`（泛林）四家核心公司、四份原始业绩公告及 `SOXX` / `AIQ` 持仓映射。
- [x] **股票近期影响速览卡（`ImpactPill` & `stock-impact-wall`）**：为 `MU`、`SKHY`、`WDC`、`LRCX`、`NVDA`、`AMD`、`ASML` 全部配置 4~16 字的 `🟢 顺风利好`、`🟠 逆风风险`、`🔍 跟踪观察` 胶囊及角色/业务纯度标签。
- [x] **基金主题配料表（`fundIngredients` & `ingredient-bar`）**：自动拆解基金在 `AI 存储链`、`AI 芯片与光刻` 与 `其他已披露持仓` 的真实权重。
- [x] **研究假设正反方拔河卡（`ai-storage-hbm` & `research-tug-board`）**：新增《从美光与海力士财报，看 AI 存储缺货与扩产传导》研究线索，并排展示看多事实胶囊与冷水提醒胶囊。
- [x] **路由与导航连通**：新增 `/research` 研究总览页、`/domains` 与 `/following` 语义路由，完整保留 `theme` 与 `node` URL 参数及站内返回焦点恢复。

### 2.2 第三步：深化普通人投研交互体验

- [x] **基金 2~3 只并排 PK 对照台（`FundsPage.tsx`）**：支持在 `/funds` 顶部自由点选 2~3 只基金（如 `SOXX`、`AIQ`、`2800.HK`、`QQQ`、`IAU`）并排对比购买门槛、主题配料条、近期影响胶囊与同日权益重叠率说明。
- [x] **组合近期核心影响体检（`PortfolioImpactHealthCard`）**：在 `/watchlist` 与 `/portfolio` 自动穿透用户已关注或已持仓的基金组合，汇总底层核心公司与宽基的 `🟢 顺风利好驱动`、`🟠 逆风风险提醒` 与 `🔍 下一步盯防` 胶囊。
- [x] **个人三态轻复盘打卡（`ResearchVerdictBar` & `saved.ts`）**：在研究详情与关注页提供 `👍 逻辑继续成立` / `🤔 存疑观望` / `🛑 逻辑失效` 一键打卡，持久化至 `sora.research.v1` 并支持跨标签页同步。

### 2.3 第四步：跨市场准入档案、数据防呆校验与仓库瘦身

- [x] **全目录跨市场准入与近期驱动档案（`fundAccessProfile`）**：覆盖 `SOXX`、`AIQ`、`QQQ`、`IVV`、`2800.HK`、`IAU` 全部 6 只代表性产品，明确美股 USD / 港股 HKD 柜台门槛与近期核心驱动胶囊，对未收录单股快照的宽基/黄金产品严格标注边界。
- [x] **研究与产业链数据防呆校验 CLI（`scripts/check-research-data.mjs`）**：自动卡控标签字数上限、发布日与核对日先后顺序、HTTPS 来源及基金目录映射，纳入 `pnpm check` 流水线。
- [x] **清理早期 Python v1 命令行遗留目录**：移除已废弃的根级 `src/sora/`、`tests/sora/`、`config/`、`main.py` 等旧版通知内核文件，保留独立运行的 `services/aktools/` 数据源服务，全面更新 `README.md` 与 `docs/` 文档体系。

## 3. 历史基础里程碑验收汇总（M0 ～ R2）

- **M0 ～ M2（基础架构、桌面端与响应式无障碍）**：完成 1440 / 1024 / 768 / 390 / 320px 全视口响应式适配、折叠导航、未保存表单变更拦截（`useUnsavedChanges`）、多币种（`CNY` / `USD` / `HKD` / `KRW`）定点估值与本地 JSON 备份恢复。

- **AKTools 实际收盘数据与领域链路（R1 ～ R2）**：通过独立 `services/aktools` 与 `apps/data-service` 买通 `.NDX`、`.INX`、`HSI` 三大指数及 `AIQ`、`SOXX`、`IAU`、`QQQ`、`IVV`、`2800.HK` 六只产品的未复权日线收盘价采集、独占锁原子写盘与 ETag 快照服务。

## 4. Phase 5：Cloudflare Worker + D1 与采集执行器

采用已确认的全 Cloudflare v2 方案：`apps/worker` 同源托管静态前端与 API，D1 保存公共研究数据和用户私有数据；`apps/data-service` 后续改为 GitHub Actions / 管理员本机运行的采集执行器。公共库仅管理员可写，普通用户可提交收录申请。

- **5.1 已完成**：0001 迁移、幂等目录种子、`/api/catalog`、ETag 与 Assets 路由、带日期和重试提示的公共目录回退、独立 Worker 构建/联调入口、CI 与隔离本地 D1 集成验收。
- **5.2 已实现**：邀请码鉴权、独立首个管理员引导、登录/注册/账号页面、管理员邀请码生成；PBKDF2、HttpOnly 会话、服务端 Turnstile、限流与 Origin 校验。
- **5.3 已完成**：`/admin` 路由守卫与账号菜单、用户查询/禁用/密码重置/角色管理、邀请码列表与撤销、审计查询；用户版本校验、会话吊销与数据库最后管理员保护。
- **5.4 已实现并通过本地验收**：搜索目录、收录申请审批、机器租约队列、本机执行器与 Actions 工作流、动态持仓 / 日线读出、标的标签维护。真实 AKTools 网络与远程 Actions 验收留到 5.6，详见 [采集说明](./INGEST.md)。
- **5.5 已实现并通过本地验收**：基金关注与持仓按账号保存、游客双模式、精确成本、版本冲突及幂等导入。详见 [个人数据说明](./PERSONAL.md)。
- **5.6 尚未开始**：远程 D1 / Secrets / Worker 部署与公网端到端验收，待产品功能确认后推进。
- **部署前产品验证**：优先完成上方领域发现主线；远程 D1/Secrets、workers.dev 部署与公网端到端验收仍待实施。

实际进度、接口衔接问题、实施顺序与各步验收见 [Phase 5 接续实施计划](./PHASE5.md)。旧的 data-service 文件 SQLite 主服务方案已被替代。
