# Post-MVP Roadmap

## Goal

Extend Sora after the first Thesis-first MVP is live.

## Candidate Tracks

### Thesis Engine Extraction

- extract stable Sora workflow into `packages/thesis`
- publish clear engine interfaces
- support additional research domains

### Agent Workflows

- automated evidence classification
- contradiction discovery
- follow-up research tasks
- question answering over thesis context

### Data Automation

- scheduled evidence discovery
- source freshness monitoring
- stronger upstream failure diagnostics
- automated data-quality checks

### Web Expansion

- agent console
- saved views
- richer exposure heatmaps
- research-card library
- notification inbox

### Integrations

- Tickeye event consumption
- Feishu / email notification delivery
- export formats for external workflows

## Non-Goals Until After MVP

- brokerage integration
- automatic trading
- personalized allocation engine
- real-time streaming
- complex charting
- multi-tenant SaaS infrastructure
