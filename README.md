# Sora

Sora is a TypeScript-based global broad index fund research platform for Chinese investors. It maps global markets to representative indexes, finds domestic ETF / ETF feeder / QDII funds, analyzes fund execution quality, and generates structured research cards and alerts.

Sora 是一个面向中国投资者的全球宽基指数基金研究平台，用于关注全球市场、映射代表性指数、寻找国内可买基金，并分析基金的溢价率、限购状态、费率、规模、夏普比率、最大回撤、跟踪误差和流动性风险。
